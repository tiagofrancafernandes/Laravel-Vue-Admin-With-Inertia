## Philosophy

AppMaker is designed around three core principles:

1. **Declarative**: Define your UI in PHP using a fluent API
2. **Zero Frontend**: No Vue/JavaScript knowledge required
3. **Convention over Configuration**: Sensible defaults with customization when needed

## Benefits

- **80% Less Code**: Compared to traditional CRUD implementations
- **Consistent UI**: All resources follow the same design patterns
- **Type-Safe**: Full PHP type hinting and IDE support
- **Extensible**: Easy to customize and extend
- **Performance**: Optimized queries with automatic eager loading
